# Pods4

Lightweight Windows desktop & system-tray app for **Samsung Galaxy Buds4 Pro** (and compatible Samsung Galaxy Buds): passthrough and noise controls over native Bluetooth Classic RFCOMM, written in **Rust**.

## Features

- **Noise Control Modes**: Off, Active Noise Cancelling (ANC), Ambient Sound (Passthrough), and Adaptive — two-way live sync with the earbuds.
- **Passthrough & ANC Levels**: 5-step Ambient Sound Volume (`Level 1`–`Level 5`) and 5-step ANC Strength (`Level 1`–`Level 5`).
- **Customize Ambient Sound**: Per-ear boost (Left / Right: `-1`, `Normal`, `+1`) and Ambient Tone (`Soft +2` to `Clear +2`).
- **Auto Switch & Passthrough Options**:
  - **Voice Detect** (auto-switch to Ambient Sound when speaking, `5s` / `10s` / `15s` timeout)
  - **Siren Detect** (auto-switch to Ambient Sound on alarms & sirens)
  - **Ambient Sound During Calls** (sidetone)
  - **Noise Controls with One Earbud**
- **Low Latency & Sync**: One-click Windows Bluetooth **Force SBC Codec (Disable AAC)** toggle (with UAC & A2DP restart), **Earbud Gaming Mode** (`ADJUST_SOUND_SYNC`), and quick access to Windows Sound Settings.
- **Live Status**: Battery & wear/charging badges for Left, Right, and Case.
- **System tray**: closing the window keeps Pods4 running in the tray. The tray icon's colour shows the current mode, its tooltip shows mode and battery, and its menu switches modes directly.
- **Low battery alerts**: a Windows notification when an earbud drops to 10 / 15 / 20 / 30 %.
- **Start with Windows**: optional; opens quietly in the tray when you sign in.
- **Proper Windows app**: per-user installer (no admin), Start menu entry, uninstall from Settings › Apps, app icon and version info, high-DPI aware, single instance (launching it again brings the window forward).

## Install

1. Download or build `Pods4.exe`.
2. Run it and click **Install** in the banner at the top (or run `Pods4.exe --install`).

Pods4 installs for the current user only and needs no admin rights:

| What | Where |
| --- | --- |
| App | `%LOCALAPPDATA%\Programs\Pods4\Pods4.exe` |
| Start menu entry | `Pods4` |
| Settings & logs | `%LOCALAPPDATA%\Pods4\` (`settings.ini`, `logs\pods4.log`) |
| Uninstall entry | Settings › Apps › Installed apps › Pods4 |
| Autostart (if enabled) | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` |

Running a newer `Pods4.exe` while an older installed copy is open offers to update it in place.
Pods4 also runs fine as a portable exe without installing.

**Uninstall:** Settings › Apps › Pods4 › Uninstall, or run `Pods4.exe --uninstall`. This removes the app, its shortcuts, startup entry, settings and logs. The Force SBC codec setting is a Windows-wide setting, so turn it off in Pods4 first if you want AAC back.

### Command-line options

| Option | Effect |
| --- | --- |
| `--tray` | Start hidden in the tray (used by Start with Windows) |
| `--install` | Install or update this copy for the current user, then start it |
| `--uninstall` | Remove Pods4 |
| `--quiet` | With `--install` / `--uninstall`: no dialogs |

## Requirements

- Windows 10 / 11 with Bluetooth
- Paired & connected Samsung Galaxy Buds4 Pro (or compatible Buds exposing Samsung SPP UUID `2e73a4ad-332d-41fc-90e2-16bef06523f2`)
- [Rust](https://rustup.rs/) to build from source; embedding the icon and version info needs a resource compiler (`rc.exe` from the Windows SDK on MSVC, or `windres` on the GNU toolchains). Without one the build still succeeds, just without the icon.

## Build & Run

```powershell
cargo test
cargo build --release
.\target\release\pods4.exe
```

The app icon is generated by `assets/make_icon.ps1`.
